CREATIVE PORTFOLIO TEMPLATE

1. Extract the ZIP file.
2. Open index.html in a browser to preview the portfolio.
3. Edit index.html:
   - Replace "Your Name" with your name.
   - Replace "YN" with your initials.
   - Replace your.email@example.com with your email address.
   - Update project titles and descriptions.
4. Replace images/project-1.svg and images/project-2.svg with your Photoshop screenshots.
   Recommended: export screenshots as JPG or PNG, then either keep the filenames and update
   the image extensions in index.html, or save your screenshots using the existing filenames
   (SVG placeholders are included as editable starter artwork).
5. Keep index.html, style.css, and the images folder together.

This is a static HTML/CSS website. No build tools are required.
